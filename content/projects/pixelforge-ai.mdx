## The problem

The IBM Bob Hackathon's challenge was to turn an idea into impact faster. Quick photo edits like removing a background or pulling a palette shouldn't need a heavy desktop editor.

## What I built

PixelForge AI is a photo editor that runs in the browser:

- **One-click background removal**, processed on the device.
- **Palette extraction** that turns any photo into a five-color HEX palette you can copy in one click.
- **Smart Suggestions:** Auto Enhance, Remove Background, Add Title, Colorize and Brighten.
- **A command box** where you type what you want done to the photo.
- **Editor tools:** text, shapes, brush and adjustments, with undo and redo, light and dark themes, and export of either the full canvas or just the photo.

## How it works

The editor is a React and TypeScript app built with Vite. Fabric.js drives the canvas and its history, and state lives in Zustand stores. Background removal and palette extraction run on the device. The command box and the image suggestions send the photo to Google's Gemini API, which returns the edit to apply.
